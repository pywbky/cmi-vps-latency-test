## CMI线路到底是什么，跟CN2、9929有什么区别

CMI全称China Mobile International，中国移动国际，对应的AS号是AS58453。简单说，这是中国移动在海外的骨干网络，专门用来优化移动用户访问境外服务器的体验。很多人把它类比成"移动版的CN2 GIA"，这个说法不算精确但方向对：CN2 GIA是电信的精品线路，9929是联通的优化线路，CMI则是移动这边分量最重的国际直连网络。

三条线路的定位其实不冲突，服务的是不同运营商用户。如果一台VPS只标榉了CN2，移动用户访问时走的可能还是普通线路，高峰期照样卡。丽萨主机这款香港VPS做的事情是三网都覆盖：去程电信走CN2、联通走AS9929（CUII），移动走CMIN2，回程则统一强制走CMI线路。这种"去程各走各的优化线路，回程全部收敛到CMI"的组合，在多篇第三方测评里都有确认，路由测试显示回程数据包无论从哪个运营商发起，最终都会经过AS58453这个节点再转发，这也是判断一台VPS是否真的走了CMI的常见方法——看路由里有没有出现223.120.x.x或223.118.x.x这类中国移动的网段。

至于该不该纠结CMI和CN2哪个"更好"，其实取决于你自己的宽带运营商和使用场景。文字站、面板类应用对带宽要求不高，走CN2或CN2 GIA的机器已经够用；但如果涉及图片、视频这种大流量场景，或者你的目标用户里移动宽带占比高，CMI线路的优势会更明显，因为它的国际出口容量普遍比CN2大，高峰期不容易出现GIA那种"降速保质量"的情况。

## 常见问题

**CMI和CN2到底哪个更快？**
不存在绝对的"哪个更快"，CN2走电信优化线路，CMI走移动优化线路，服务对象不同。丽萨主机这款VPS的做法是去程分流三网各走各的优化线路，回程统一收敛到CMI，相当于把三家运营商的优化能力都占了，实测数据显示三网延迟都控制在合理区间。

**这款VPS的IP是住宅IP吗？**
不是。多个IP质量数据库检测结果显示这是机房（hosting/isp）属性IP，欺诈分很低、适合正常建站和代理使用，但不具备住宅IP的强匿名效果，两者用途不能混淆。

**支持Windows系统吗？**
根据产品说明，这款VPS支持安装Windows系统，具体版本以后台可选镜像为准。

**流量超了会怎样？**
按照官方条款，超出分配带宽或流量会导致服务被暂停，等到流量重置周期（每月1号或续费日）后自动恢复，不会直接扣费或强制升级套餐。

**48小时退款有什么限制？**
使用流量超过分配额度5%或20GB（取较小值）就不再符合退款条件，另外设置费、支付手续费等特定费用本身不可退。

CMI线路的核心价值就是给移动用户一条更稳的国际直连通道，丽萨主机这款香港VPS把三网优化都做了，实测延迟和丢包数据也站得住脚，价格区间覆盖了从轻量应用到大流量商用的不同需求。选哪个套餐主要看你的流量预算和用途，入门建站用基础版或年付版基本够用，真要做大流量业务再考虑不限流量档位。
